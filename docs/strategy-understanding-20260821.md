# 策略行为理解（截至 2026-08-21）

本文记录截至 2026-08-21 对生产策略行为的核实结果，重点说明组合止盈、再平衡和后触发新仓之间的关系。文中的“实际金额”以服务器 `state.db` 中的订单/成交与持仓记录复核；它是行为说明，不是新的参数配置。

## 结论摘要

1. 组合止盈会处理触发瞬间已经存在的仓位，但当前周期触发后仍允许策略继续开仓。
2. 后触发新仓不会自动纳入已经完成的组合止盈计划，因此不继承这次组合级权益回吐保护。
3. 当前再平衡使用动态目标持仓数。组合止盈清掉较多仓位后，目标持仓数变小，后续新仓的目标金额可能明显放大。
4. 入场前再平衡是 `reduce_only`，只会缩小超目标的已有仓位，不会给低于新目标的已有仓位补仓。
5. `rebalance_after_entry = true` 虽然存在于配置，但截至本文记录的代码路径，入场流程没有实际调用入场后的完整再平衡；不能把它当成已生效的补仓功能。

## 组合止盈的当前行为

当前组合止盈参数为：

- 启动涨幅：`+2.5%`；
- 峰值利润回吐：`15%`；
- 组合止盈按账户分别记录权益基准、峰值、移动触发线和完成状态；
- acc01：组合止盈开启，触发后减仓 `50%`；
- acc02、acc03：组合止盈开启，触发后清仓 `100%`；
- acc04：组合止盈关闭，但仍有独立的组合止损保护；
- 组合止损是独立于组合止盈的账户级保护，当前阈值为相对周期基准 `-3.5%`，四个账户分别计算；
- 组合止盈触发后不会锁定本周期后续入场。

因此，“组合止盈已经触发”只表示触发时已有仓位的那次组合退出计划已经锁存并执行，不表示当天后续所有新仓都受到同一条组合止盈线约束。

## 再平衡金额公式

当前生产配置为：

```text
leverage = 2
rebalance_utilization = 0.6
rebalance_mode = equal_risk
```

目标总名义金额：

```text
target_gross_notional = account_equity × leverage × rebalance_utilization
                       = account_equity × 1.2
```

目标单仓金额：

```text
target_notional_per_position = target_gross_notional / target_count
```

当前 `target_count` 的实际语义是：

```text
target_count = 当前已有 active symbol 数量 + 本轮新候选 symbol 数量
```

它不是始终固定为 `top_n = 10`。`virtual_slots` 用于表示目标持仓数中尚未由当前已有仓位占用的槽位；在 `equal_risk` 模式下，单仓金额直接按 `target_count` 平均分摊。

### 入场前再平衡

入场前调用再平衡时使用 `reduce_only = true`：

- 当前名义金额高于目标：通过买入平仓缩小仓位；
- 当前名义金额低于目标：禁止卖出加仓，已有仓位保持原数量；
- 目标金额只会影响后续新仓的开仓金额。

当前仓位的名义金额判断为：

```text
current_notional = abs(positionAmt) × markPrice
deviation = target_notional - current_notional
```

当 `deviation > 0` 时，入场前的 `reduce_only` 再平衡会跳过，不会补仓。

## acc01 的 BOME 金额口径

此前表格把 acc01 组合止盈后的剩余金额误标为“触发前普通仓位”，导致 BOME 看起来像异常放大。正确口径如下：

- acc01 触发前的原始开仓金额约为 `30.17 USDT`；
- 组合止盈触发后，旧仓按 `50%` 减仓，很多仓位剩余约 `15.07 USDT`；
- BOME 在组合止盈触发之后才开仓，未进入本轮组合止盈计划，因此保持完整的约 `30.16 USDT`；
- 所以 BOME 与 acc01 原始开仓金额一致，只是与已经减半的旧仓当前剩余金额不一致。

复核示例：

```text
ACE 原始：120.17 × 0.25103 ≈ 30.17 USDT
ACE 减仓后：约 15.08 USDT

BOME：25913 × 0.0011639 ≈ 30.16 USDT
```

`COLLECT` 的组合止盈半仓限价成交记录已存在，但 `positions.qty` 仍保留全量的同步异常；分析原始金额时应优先使用入场订单事件中的 `origQty` 和成交价，不能只读当前 `positions.qty`。

## 数据分析口径

比较仓位大小时应区分：

- 原始开仓金额：入场订单的实际成交数量 × 入场成交价；
- 当前剩余金额：当前交易所仓位数量 × 当前标记价；
- 组合止盈效果：应按触发前后分阶段、控制后续新仓金额后比较，不能只用一条全周期权益曲线判断。

否则会把“旧仓被减仓”“后触发新仓未受组合止盈约束”和“再平衡放大新仓”混成一个结果。

## 待明确的策略决策

如果希望组合止盈之后不再产生未受组合保护的新风险，需要在策略层明确选择：

1. 组合止盈触发后，直到下一个日周期切换前禁止新开仓；或
2. 允许新开仓，但为后触发新仓建立新的组合止盈子周期；或
3. 允许新开仓，但限制其目标单仓金额不超过触发前的基准金额。

在未作出选择前，不应把后触发新仓的收益或亏损直接归因于原组合止盈功能。
